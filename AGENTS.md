# Agent guidance — php-io-extensions/vlc

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **Bindings are 1:1 at the libvlc 3.0 API**: every `LIBVLC_API` function outside `deprecated.h` that the 3.0.24 library exports (277 of 282; [`SUPPORT.md`](SUPPORT.md) lists the five that are not and why). Function and constant names are the C names. No defaults, no composites, no glue beyond what `bindings.json` lists. A need of code built on the extension is solved in that code, not here.
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   Kept refusals: `vlc-no-instance`, `vlc-released-handle`, `vlc-list-count` ([`.okf/architecture/handles-and-callbacks.md`](.okf/architecture/handles-and-callbacks.md)), each with its probe in `tests/Probes`.
4. **Translations, the only ones.** An opaque libvlc type is a handle class. A list element (`libvlc_audio_output_t`, `libvlc_media_track_t`, ...) is a handle whose C fields are live read-only properties; libvlc owns it until its `*_release`, which takes the list back. `libvlc_event_t`, `libvlc_media_stats_t`, `libvlc_video_viewpoint_t` and `libvlc_dialog_cbs` are value objects. An out-parameter is by-reference. A pointer + count is a PHP list with the count its own parameter in C order. `void *`, `FILE *`, drawables and video planes are `int` addresses. A `char *` result is a copied string, freed with `libvlc_free`. Failure is libvlc's return value.
5. **Handles.** `final`, private `__construct`, not cloneable, not serializable, `pointer(): int` (0 once released), `static fromPointer(int $pointer): ?static` (null for 0). One PHP object per (native pointer, class) per thread (`vlc_box`). The seven reference-counted classes count the references the binding handed out (`vlc_ref_add` / `vlc_ref_drop`); the `*_release` that reaches zero releases the handle. A released handle reaching libvlc is refused.
6. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the libvlc headers; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. A throw on an added line needs a `/* binding:<id> */` marker naming a site, unless it sits inside a `helpers.marshal` function (`vlc_handle_arg`, `vlc_list_count`, `vlc_list_ptrs`, `vlc_strings_from`). One marker marks one line. A `PHP_FUNCTION` must be written out, not made by a macro. `/opt/homebrew/bin/python3 ~/.agent-guards/ext-guard.py tree .` prints `clean` when the tree passes.
7. **Callbacks.** libvlc calls back on its own threads; PHP never runs there. Every callback goes through `src/queue.c`: a call whose result libvlc waits for (media open/read/seek, audio setup, video lock/format, log) waits up to its deadline for the owner thread's next VM interrupt, then gets its no-op; event and exit-handler calls are copied, the libvlc thread let go, then the callable runs; void calls (audio, video unlock/display, dialogs, cleanups) are posted and libvlc never waits. Request end gives every record its no-op; libvlc keeps the records.
8. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, commit both. Never hand-edit `*_arginfo.h`. `stubs/gen_*.stub.php` and `src/gen_*.c` come from `php84 tools/generate.php <group>`; `stubs/constants.stub.php` from `php84 tools/constants.php`: rerun the tool, never edit its output. `@param list<…>` breaks gen_stub; describe lists in prose.
9. **Build.** `./install-macos.sh` (against `/Applications/VLC.app`) into Homebrew `php@8.4` and `php@8.4-zts`. On the Pi, copy the tree through `fnk`, `sudo apt install libvlc-dev vlc-plugin-base`, `./install-debian-trixie.sh`. Pest at `-d memory_limit=128M`. Mac tests use `VLC_TEST_ARGS` (`--aout=dummy --vout=dummy`): never make sound or open a window in a Mac test. Gate a commit on the suite's exit code.
10. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`. After a binding change run `php84 scripts/support.php`.
11. **Version** is `PHP_VLC_VERSION` in `php_vlc.h`: 0.11.0. `os-families`: linux, darwin.
