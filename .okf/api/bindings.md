# Overview

277 of the 282 `LIBVLC_API` functions of the libvlc 3.0.24 headers outside deprecated.h. Not bound: `libvlc_vprinterr` (a `va_list`), and four functions the 3.0.24 library declares but does not export (`libvlc_media_player_set_evas_object`, `libvlc_vlm_get_media_instance_title`, `_chapter`, `_seekable`). deprecated.h is out of scope by decision.

# Where each function lives

* `stubs/vlc.stub.php` — `libvlc_get_version`, `_compiler`, `_changeset` (src/vlc.c).
* `stubs/libvlc.stub.php` — libvlc.h and libvlc_media.h without callbacks (src/libvlc.c).
* `stubs/gen_<group>.stub.php` — generated by `tools/generate.php <group>`: player, lists, discovery, vlm, dialog. Plain shapes only: handles, integers, floats, bools, strings, `void *` addresses.
* `stubs/player.stub.php`, `discovery.stub.php`, `vlm.stub.php` — what the generator leaves to hand: out-pointers, list arrays, the viewpoint, option string lists, and the releases that free handles.
* `stubs/callbacks.stub.php` — every function that takes a callback, `libvlc_log_*`, `libvlc_audio_set_format`, `libvlc_video_set_format` (src/callbacks.c).
* `stubs/types.stub.php` — the handle, list-element and value classes (src/types.c).
* `stubs/constants.stub.php` — generated by `tools/constants.php`: 218 enumerators and 8 integer defines.
